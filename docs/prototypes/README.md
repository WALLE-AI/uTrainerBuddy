# 研究工作台交互提案

2026-11-10。可点击原型：[research-workspace.html](research-workspace.html)。截图：[计划](research-overview.png)、[运行详情](research-detail.png)、[运行对比](research-compare.png)。全部为示例数据，未接入模型或执行器，不代表产品功能已完成。

## 与现有实现对照

以 `frontend/desktop/src/renderer/components/layout/ProjectWorkbench.tsx`、`Layout.tsx` 和现有 Preview 为依据。首页与 Agent 会话保持现有实现；原型中的左栏、消息和输入框仅用于说明新增交互的位置，不是替换稿。

| 现有交互与实现状态 | 研究功能放置方式 |
| --- | --- |
| 计划：读取当前会话最新 plan 消息，进度、刷新、讨论计划已实现 | 在计划标签内逐步补研究目标、约束、baseline 和实验引用；不再增加独立“概览”导航 |
| 运行：标签存在，当前内容为空 section | 填入实验/Run 列表与父子关系，点击后在同标签内查看详情；比较也是该标签内的子视图 |
| 产物：标签存在，当前内容为空 section | 展示指标报告、检查点和证据，关联来源 Run；文件内容复用既有 Preview |
| 动态：标签存在，当前内容为空 section | 展示状态转换、失败、取消、结果到达等事件，支持定位运行与引用 |
| 文件：已有 ProjectFiles | 保留文件树及其操作，不另建“研究文件管理器” |
| 固定来源会话、展开/收起、按会话记忆标签 | 保留；研究对象必须显示来源。固定旧会话后，引用仍发送到当前会话，不静默改绑 |
| Preview：已有独立多标签文件/浏览器预览区，项目级托管 | 继续使用现有预览区域与宽度/最大化逻辑；工作台和预览不是同一个面板，不用研究详情替换文件预览 |

原型演示五个标签、计划/实验卡片定位、Run 详情返回、配方/日志/产物切换、缺指标比较、引用到现有输入框、固定提示、展开/收起，以及暂停研究与取消 Run 分离。固定按钮仅演示当前会话提示，不声称已实现跨会话数据切换；文件标签只示意现有能力，不重新实现编辑器。

实施顺序：先盘点对象/API与事件映射，然后填充现有工作台。无需新增首页、聊天页或第二套右侧导航。原型从此前“概览/实验/比较”三个顶层标签修正为用户已有的五标签结构。

验证：独立 Electron 窗口生成截图并执行 DOM 交互断言，覆盖草稿保留、配方标签、暂停不取消 Run、取消确认、缺失结果不宣称成功、复用唯一输入框；不操作用户运行中的 Electron 应用。
