# uTrainerBuddy 应用图标

设计：用 U 形轮廓组成一个微笑的智能伙伴，右侧笔画向上延伸为箭头，表达模型训练与持续提升。靛紫色延续桌面端现有配色，薄荷色双眼提供轻微的视觉区分。

- `utrainerbuddy-icon.svg`：主图标矢量源文件，透明圆角外缘。
- `utrainerbuddy-mark.svg`：单色标识，适用于浅色页面与印刷。
- `utrainerbuddy-icon-1024.png` / `utrainerbuddy-icon-512.png`：高清透明背景 PNG。
- `utrainerbuddy-icon.ico`：Windows 图标，包含 16、24、32、48、64、128、256 像素尺寸。
- `utrainerbuddy-icon-preview.png`：主图标及小尺寸呈现预览。

已接入正式首页及共享左栏左上角的品牌标识，资源位于 `frontend/desktop/src/renderer/assets/utrainerbuddy-icon.svg`。Windows 任务栏图标仍未替换。
