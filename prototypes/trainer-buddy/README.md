# uTrainerBuddy：Agent 中心三栏交互原型

双击 `preview.html` 即可离线体验，无需依赖或启动 frontend。HTTP 服务默认入口为 `index.html`，与 `agent.html` 内容一致。

新版按用户要求：**左侧组织项目和会话，中间始终与 Harness Agent 交互，右侧观察与操作对象。** 所有修改位于独立原型目录及方案文档，未改动现有 frontend 源码。

## 三栏职责

| 位置 | 内容 | 关键交互 |
| --- | --- | --- |
| 左侧 | 项目、新建/搜索、会话、资源索引、任务、算力与扩展 | 切换会话恢复草稿；资源打开右侧，不替换聊天 |
| 中间 | Agent 回复、折叠工具活动、计划/任务/结果卡、业务问题、输入框 | 继续讨论；引用证据；选择引擎；停止回复 |
| 右侧 | 计划、运行、资产、记录 | 检查数据/训练/评测；固定监控对象；拖动调宽与收起 |

## 建议体验

1. 默认会话为“长尾场景优化”。点击训练卡的“打开监控”或“日志”，中心仍保持当前会话。
2. 在右侧点固定按钮，再切换左侧“构建售后数据集”，观察训练监控保留且标明来源会话。解除固定后，后续会话切换跟随其上下文。
3. 在输入框写一段未发送的草稿，切换会话再回来，检查草稿恢复。
4. 点击右侧“引用这段指标”，引用加入中心输入框；发送后显示模拟回复。打开右侧对象本身不会自动发送给 Agent。
5. 数据会话 → 审核样本 → 编辑并通过或排除；重试失败分片后，在版本血缘中冻结新版本。
6. 左侧算力连接 → 模拟断开；右侧训练 → 取消训练，显示“等待取消确认”；恢复连接后确认取消。
7. 评测资源 → 完成评分演示；对比分数状态、切片与发布门槛。
8. 研究会话 → 右侧计划；修改目标与预算，提交一次本地演示任务，进入后台任务中心查看。
9. 新建会话，选择四类起点之一；发送后点停止按钮，后台训练状态保持独立。

## frontend 参考与实现边界

参考现有 Layout 的会话主区域与可调侧栏、ProjectPanelHost 的项目级宿主、Preview 的对象预览，以及 SendBox 的输入与上下文扩展方式。常规展开右栏不隐藏中心会话。产品、技术和 UI 方案已同步这一布局约束。

所有模型、指标、服务器、日志、回复和动作都是模拟数据。不连接 SSH，不调用 Agent 引擎、Skill 或 MCP，不提交 GPU 任务，不启动推理服务。附件仅展示文件名，不读取或上传内容。

会话草稿、引用、监控固定与任务状态仅保存在当前页面内存，刷新会重置。图表和资源为固定快照，不代表实时采集；评测完成按钮切换到预设最终结果。正式产品需由 Rust Backend 提供权威状态和事件。

已进行脚本语法与隔离的交互状态检查，覆盖中心会话保持、固定观察、草稿引用、回合停止、异步回复归属、数据审核、取消对账、计划幂等和输入转义。当前浏览器工具不可用，尚未完成真实浏览器操作与视觉验收。

## 文件

- `agent.html`：新版 HTML 壳；`index.html` 是打包脚本生成的同内容默认入口。
- `agent.css` / `agent.js`：新版独立样式与交互。
- `preview.html`：新版单文件离线交付版。
- `lifecycle-preview.html`：保留的旧版单文件原型，用于对照。
- `lifecycle.html` / `styles.css` / `app.js`：旧版源文件。

修改新版后重新生成：

```powershell
python prototypes/trainer-buddy/build-preview.py
```

脚本只读写本原型目录，不依赖 frontend 工程。
