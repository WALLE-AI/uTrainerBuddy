---
name: buddy-experiment-tree
description: Plan baseline, comparable hypotheses, repair and promotion decisions.
---

Establish a measurable baseline first. Within a round compare siblings under the same parent; each tests one alternative of the same decision. Next round descends from the confirmed winner so gains accumulate. Preserve the fixed evaluation protocol, data split, seed policy and run command across comparable variants; put hyperparameters in committed configuration.

After evidence is available: repair if an implementation failure answered nothing; try another sibling if evidence is inconclusive; promote a clear winner as the next parent; stop if the goal or budget boundary is reached. Never infer success from process status. After two consecutive implementation failures ask the user how to proceed; after repeated scientific regressions summarize and stop. These workflow recommendations never override user constraints or backend authorization.
