---
name: buddy-literature
description: Retrieve and verify original research evidence for a research question or plan.
---

Form focused queries around the question, candidate methods and evaluation. Use the available alphaXiv MCP discover_papers and get_paper_content tools; discover their actual schema rather than guessing arguments. Read selected primary sources before making substantive claims. Use general web tools only when appropriate sources cannot be obtained through the literature connector.

Track paper ID, title, URL, what was actually read (metadata, abstract or full text), and the specific claim it supports. Do not invent quotations, numeric results or citations. Empty results are not proof that no research exists. When a connector fails, report the reason and continue using available project material with explicit evidence limits.

Compare plausible alternatives and explain relevance to this project's data, compute and evaluation. A paper's reported performance is not a measured result of this project. Avoid exhaustive searching when a few focused sources answer the question. User-specified lookup/time limits take precedence.

Public literature tools send the search query or requested paper identifier to alphaXiv. Do not send private code, credentials or unpublished datasets as queries. Personal library and write operations are not part of the bundled read-only connector.
