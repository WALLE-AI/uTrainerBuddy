---
name: buddy-figures
description: Produce clear experiment figures from verified measurements.
---

Load buddy-results and retrieve actual data first. Select one primary visual for the question: training curves, comparable final scores or a resource/quality tradeoff. Label metric, units, steps, variants and uncertainty. Distinguish missing values from zero and show only observed ranges.

Preserve source CSV/JSON and plotting code beside the figure. Use legible fonts and consistent colors; check the rendered output and cite contributing Run IDs. Do not fabricate error bars or duplicate the same comparison in several charts. If there are no real measurements, explain in prose instead of generating a placeholder figure. Registered run artifacts must be written by the approved recipe to TRAINERBUDDY_OUTPUT_DIR; document reports can link existing project files.
