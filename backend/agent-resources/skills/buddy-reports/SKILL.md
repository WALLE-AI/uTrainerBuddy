---
name: buddy-reports
description: Deliver durable research findings with traceable sources and reproducibility limits.
---

Inspect existing project plans and reuse the relevant document for follow-up findings. Until a dedicated artifact writer is available, save a research report with research_document_write and a descriptive title; cite its actual returned path. Do not claim that an arbitrary file is registered as a run artifact.

Separate observed project evidence, published findings and proposed experiments. Include the research question, sources, methods, findings, limitations and next decisions. For measured comparisons require real run evidence; never turn a plan or process status into numeric results. Preserve published paths and previous user edits.

Use one primary representation for a comparison. Figures require source data and a reproducible plotting script. Skip charts when no measurements exist. Model delivery requires verified checkpoint location and availability, code/environment/data versions, evaluation evidence and reproduction instructions.
